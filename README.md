# 전주대학교 대동제 및 해커톤 로그 데이터 추출 프로그램

## 1. 프로그램 소개

이 프로그램은 정규표현식(`re`)을 사용하여 텍스트 파일에서 필요한 정보를 찾아 출력하는 Python 프로그램입니다.

## 2. 실행 방법

1. Python 파일과 로그 TXT 파일을 같은 폴더에 넣습니다.
2. Python 파일을 실행합니다.

```bash
python 파일이름.py
```

프로그램에서 읽는 TXT 파일 이름은 다음과 같습니다.

```text
07-02. 전주대 대동제 및 해커톤 통합운영 데이터 로그(1).txt
```

## 3. 코드 설명

### ① 라이브러리 불러오기

```python
import re
```

정규표현식을 사용하기 위해 `re` 라이브러리를 불러옵니다.

### ② 파일 읽기

```python
with open("07-02. 전주대 대동제 및 해커톤 통합운영 데이터 로그(1).txt",
          "r", encoding="utf-8") as f:
    text = f.read()
```

- `open()`을 사용하여 텍스트 파일을 엽니다.
- `"r"`은 읽기 모드입니다.
- `encoding="utf-8"`은 한글이 깨지지 않도록 설정합니다.
- `read()`는 파일의 전체 내용을 읽습니다.

### ③ 이메일 추출

```python
emails = re.findall(
    r'[\w.+-]+@[A-Za-z0-9-]+(?:\.[A-Za-z0-9-]+)*\.[A-Za-z]{2,}',
    text
)
```

정규표현식과 일치하는 이메일 주소를 모두 추출합니다. 도메인 부분이 비어 있는 잘못된 이메일 형식은 제외합니다.

### ④ 휴대폰 번호 추출

```python
phones = re.findall(
    r'(?<!\d)010[-. ]\d{4}[-. ]\d{4}(?!\d)',
    text
)
```

010으로 시작하고, 숫자 구간이 각각 4자리인 휴대폰 번호를 추출합니다. 숫자 사이에는 하이픈, 마침표 또는 공백이 올 수 있습니다.

### ⑤ 학번과 학과 추출

```python
students = re.findall(
    r'\[\s*(202\d{6})\s*/\s*([가-힣]+(?:학과|학부))\s*\]',
    text
)
```

대괄호 안에서 202로 시작하는 9자리 학번과 학과 또는 학부명을 함께 추출합니다.

### ⑥ GitHub 주소 추출

```python
github = re.findall(
    r'https?://github\.com/[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+(?:\.git)?',
    text
)
```

GitHub 저장소 주소를 추출합니다. GitLab 주소는 추출하지 않습니다.

### ⑦ 쿠폰 코드 추출

```python
coupons = re.findall(
    r'\bFEST-2026-[A-Z0-9]{4}\b',
    text
)
```

`FEST-2026-`으로 시작하고 뒤에 영문 대문자 또는 숫자 4자리가 오는 쿠폰 코드만 추출합니다.

### ⑧ 매출 추출 및 합산

```python
sales = re.findall(r'매출:\s*([\d,]+)\s*원', text)
total = sum(int(s.replace(',', '')) for s in sales)
```

- `re.findall()`로 각 부스의 매출 금액을 추출합니다.
- `replace(',', '')`로 금액의 쉼표를 제거합니다.
- `int()`로 문자열을 숫자로 변환합니다.
- `sum()`으로 모든 부스의 매출을 합산합니다.

### ⑨ 결과 출력

```python
print()
```

추출한 결과를 항목별로 화면에 출력합니다.

```python
for item in emails:
    print(item)
```

`for`문을 사용하여 추출된 정보를 하나씩 출력합니다.

```python
print(f"\n전체 매출 합계: {total:,}원")
```

전체 매출 합계를 천 단위 쉼표가 포함된 형태로 출력합니다.

## 4. 추출 항목

프로그램은 다음 6가지 항목을 추출합니다.

1. 이메일 주소
2. 휴대폰 번호
3. 학번 및 학과
4. GitHub 저장소 주소
5. 2026년 쿠폰 코드
6. 부스별 매출 및 전체 매출 합계

## 5. 사용한 주요 함수

| 함수 | 기능 |
|---|---|
| `open()` | 텍스트 파일 열기 |
| `read()` | 파일 전체 내용 읽기 |
| `re.findall()` | 정규표현식과 일치하는 모든 내용 찾기 |
| `replace()` | 문자열의 특정 문자 바꾸기 |
| `int()` | 문자열을 정수로 변환하기 |
| `sum()` | 숫자들의 합계 계산하기 |
| `print()` | 결과 출력하기 |

## 6. 마무리

이 프로그램은 정규표현식을 이용해 하나의 텍스트 파일에서 여러 종류의 정보를 조건에 맞게 추출합니다. 추출한 매출 금액은 숫자로 변환하여 전체 합계를 계산합니다.
